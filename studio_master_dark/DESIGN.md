## Brand & Style

This design system channels the refined, hyper-focused atmosphere of professional recording control rooms and boutique master engineering suites. Engineered for sound engineers, touring musicians, venue techs, and gear warehouse managers, the interface feels like high-precision studio hardware: tactile, unyielding, and impeccably calibrated.

The aesthetic fuses **Modern Studio Dark** with **Precision Instrument Functionalism**:
- Deep, low-reflectance charcoal and obsidian canvas layers minimize eye fatigue during extended late-night backoffice shifts and high-stakes procurement sessions.
- Luminous warm amber and brushed vintage brass accents serve as precision status monitors, evocative of vintage vacuum tube glow, analog VU meters, and brushed hardware faceplates.
- High structural discipline ensures instant readability across complex multi-attribute catalogs, real-time inventory matrices, and high-density telemetry spec tables.

## Colors

The palette is tuned around analog hardware telemetry, dark anodized aluminum, and warm incandescent indicator lights.

- **Primary (`#F59E0B` - Radiant Amber):** The core focal point for primary interactions, high-value triggers, key checkout CTAs, and active studio channel toggles. Emits an authentic vacuum-tube warmth against deep neutrals.
- **Secondary (`#D97706` - Burnished Brass):** Used for focused UI states, secondary controls, category hierarchy markers, and active filters.
- **Tertiary (`#10B981` - Master Bus Green):** Represents live warehouse connectivity, verified physical stock ("In Rack / Ready to Ship"), and calibrated audio signal integrity.
- **Neutral (`#0F1115` - Anodized Obsidian):** Serves as the bedrock dark foundation, paired with tiered surface container steps:
  - Surface Root: `#090A0D`
  - Surface Flat: `#0F1115`
  - Surface Raised / Card: `#161920`
  - Surface Overlay / Modal: `#1E222B`
  - Surface Elevated Active: `#282D37`
  - Hairline Border / Grids: `#262B35` (15% - 30% alpha for low-glare division)

## Typography

Typography balances technical authority with rigorous optical legibility:

- **Headlines & Mastheads (Space Grotesk):** Engineered geometric grotesque with subtle industrial idiosyncrasies. Used for prominent product titles, gear model numbers, and dashboard category overviews.
- **Body & Continuous Copy (Inter):** Highly neutral, screen-optimized sans-serif designed for frictionless reading in low-light environments across lengthy audio gear descriptions, warranty details, and inventory audit logs.
- **Labels, Telemetry & Specs (JetBrains Mono):** Dedicated fixed-pitch monospaced font for rack units (e.g., `19" 2U`), dynamic frequencies (`20Hz - 20kHz`), impedance values (`600Ω`), serialized barcode strings, inventory counts, and backoffice warehouse SKU locators.

## Layout & Spacing

The layout is constructed on an 8-point base grid (subdivided to 4-point for micro-spec alignment and telemetry bars), utilizing a 12-column fluid grid system across tablet and desktop viewports, downscaling to a 4-column structure on mobile.

- **Desktop (>= 1280px):** 12 columns with 24px gutters and 48px outer page padding. Multi-pane workflows dominate: persistent left collapsible console navigation (260px fixed width), dual-split gear spec sheets, and right-hand telemetry sidecars for live order manifests.
- **Tablet (768px - 1279px):** 8 columns with 24px gutters and 32px margins. Backoffice navigation folds into an overlay tray or compact icon rail. Spec comparison matrices convert to horizontally swipeable segmented panes.
- **Mobile (< 768px):** 4 columns with 16px gutters and 16px margins. High-density data tables transform into modular, stackable card strips with sticky bottom actions for procurement triggers.

## Elevation & Depth

To sustain the pro-audio hardware atmosphere, depth is communicated through **stacked tonal surfaces** and **micro-ambient luminescence** rather than overt, distracting drop shadows:

- **Level 0 (Chassis Ground - `#090A0D`):** Deepest recessed base plate used for app canvas backgrounds and deep tabular backdrops.
- **Level 1 (Rack Surface - `#161920`):** Standard resting plane for product tiles, equipment panels, inventory cards, and backoffice data containers. Defined with a crisp 1px perimeter outline (`#262B35`).
- **Level 2 (Active Module - `#1E222B`):** Hovered cards, flyout drawers, active audio channel selectors, and elevated table header groupings. Features a faint outer ambient shadow: `0 8px 24px rgba(0, 0, 0, 0.55)`.
- **Level 3 (Command Overlay - `#282D37`):** Modals, parameter adjustment overlays, real-time inventory allocation panels, and floating status bars. Enforced with a warm amber-tinted shadow: `0 16px 40px rgba(0, 0, 0, 0.7), 0 0 1px rgba(245, 158, 11, 0.25)`.
- **Subtle Glow Effects:** Dedicated interactive elements (such as "Live" warehouse indicators and toggled parameter switches) utilize an internal optical bloom (`box-shadow: 0 0 12px rgba(245, 158, 11, 0.3)`).

## Shapes

The shape system adopts a **soft, machine-milled corner radius (`roundedness: 1`)**. 

- Standard inputs, buttons, spec badges, and stock chips use a baseline radius of `0.25rem` (4px).
- Enclosing product containers, equipment specification blocks, and data grid cards implement `0.5rem` (8px).
- Floating contextual overlays and drawer panels cap at `0.75rem` (12px).

This tight, calibrated geometry mirrors the precision laser-cut faceplates, rack ears, and machined anodized chassis of studio-grade hardware, deliberately eschewing overly playful circular or pill-shaped treatments.

## Components

### Buttons
- **Primary Action:** Solid background `#F59E0B`, text `#090A0D` (Inter SemiBold), 4px radius, 40px height for desktop. Subtle inner top-edge highlight (`inset 0 1px 0 rgba(255, 255, 255, 0.2)`). Hover transitions to `#D97706`.
- **Secondary / Rack Tool:** Translucent `#1E222B` body with a 1px border (`#262B35`), text `#F3F4F6`. On hover, the border shifts to `#F59E0B` with an amber text tint.
- **Ghost / Utility:** Transparent with muted text (`#9CA3AF`), shifting to full white on hover with a subtle `#161920` background pill.

### Badges & Warehouse Inventory Tags
- Designed using `JetBrains Mono` at `label-sm` (uppercase, tracked out +0.08em).
- **In Stock / Real-Time Validated:** Background `rgba(16, 185, 129, 0.12)`, border `1px solid rgba(16, 185, 129, 0.35)`, text `#10B981`, featuring a pulsating 6px green LED indicator dot.
- **Low Stock / Backorder:** Background `rgba(245, 158, 11, 0.12)`, border `1px solid rgba(245, 158, 11, 0.35)`, text `#F59E0B`.
- **Depleted / Discontinued:** Background `rgba(239, 68, 68, 0.1)`, border `1px solid rgba(239, 68, 68, 0.25)`, text `#EF4444`.

### Technical Spec Tables
- Monospaced numerical values aligned flush-right; parameter keys aligned flush-left in muted gray (`#9CA3AF`).
- Alternating row styling using ultra-subtle zebra striping (`#161920` vs `#11141A`) delimited by hairline rules (`#222731`).
- Interactive copy-to-clipboard functionality for technical parameters (e.g., dimensions, frequency response curves, power requirements).

### Input Fields & Search Bars
- Background `#11141A`, border `1px solid #262B35`, text `#F9FAFB`, placeholder text `#4B5563`.
- Active focus displays a 1px solid `#F59E0B` outline paired with an amber glow: `0 0 0 2px rgba(245, 158, 11, 0.15)`.
- Global search includes a keyboard accelerator indicator chip (`⌘K` or `Ctrl+K`) styled in JetBrains Mono.

### Cards (Product & Inventory Racks)
- Dark raised surface `#161920` with 8px radius and 1px border (`#262B35`).
- Integrated image wells feature an ultra-dark gradient background (`#090A0D` to `#161920`) ensuring bright chrome knobs, dark wood guitar finishes, and black microphone chassis stand out cleanly.
- Hover states initiate a smooth border transition to `#374151` and lift the container with an ambient elevation-2 shadow.

### Checkboxes & Toggle Switches
- Checkboxes: 16x16px square with 2px corner radius; dark slate fill with a 1px border. Checked state renders `#F59E0B` fill with an obsidian checkmark.
- Rocker Toggles: Built as miniature console toggle switches with clear visual states (lit LED indicator in amber when active).
